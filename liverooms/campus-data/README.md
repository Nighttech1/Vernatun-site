# Данные комнат Кампуса (Vernatun Lounge)

Простыми словами: здесь лежат **файлы живых комнат** — чат, сессия и папка для будущих вложений.  
Это **не** база Sputnik и **не** память Cortana — их трогать нельзя.

## Где это на компьютере (localhost)

По умолчанию API смотрит сюда:

`liverooms/campus-data/`

(полный путь рядом с проектом, например  
`e:\Applications\Vernatun\liverooms\campus-data\`)

Переменная окружения: `LOUNGE_CAMPUS_DATA`  
Если её не задали — используется эта папка.

## Где это на сервере (VPS) — позже, после приёмки

Когда Кампус вынесут на прод, нужно будет указать:

```
LOUNGE_CAMPUS_DATA=/var/www/vernatun/campus
```

Сейчас **деплой на VPS не делаем** — только localhost, пока Клиент не скажет «деплой Кампус».

## Что лежит внутри

Список комнат (названия в лобби) — **отдельный файл**, не здесь:

- каталог из 10 комнат: `liverooms/infra/vps/rooms.json`
- динамические комнаты: `rooms_dynamic.json` (сейчас пустой `[]`, создание с сайта выключено)

А вот **материалы каждой комнаты** — здесь:

```
campus-data/
  rooms/
    mansarda/
      chat.json       # сообщения чата (создаётся при первом использовании)
      session.json    # таймер сессии ~1.5 ч (создаётся при входе)
      uploads/        # пустая папка под будущие файлы с доски/вложений
    ara-uvazhaesh/
      ...
    (ещё 8 комнат — те же три слота)
```

Идентификаторы папок совпадают с `id` в `rooms.json`  
(например `jan-kofe`, `shashlyk`, `glendale`).

## Что происходит при сессии

- Первый вошедший в пустую комнату становится **хостом** (ведущим).
- Сессия ~1.5 часа; когда комната пустеет (LiveKit подтвердил 0 человек),  
  сервер может очистить `chat.json` и `session.json` и содержимое `uploads/`.
- Сама комната из каталога (название в лобби) **не удаляется**.

## Доска (whiteboard / tldraw)

Пока доска живёт **только в браузере** (IndexedDB на устройстве пользователя).  
На сервер в `uploads/` она ещё **не** сохраняется — это следующая волна.  
Поэтому смена компьютера или очистка браузера может «потерять» доску; чат на сервере — отдельно.

## Важно для владельца

| Что | Где | Можно ли удалять «на всякий случай» |
|-----|-----|-------------------------------------|
| Названия 10 комнат | `rooms.json` | Нет без задачи |
| Чат / сессия комнаты | `campus-data/rooms/<id>/` | Не стирать без просьбы |
| База Sputnik / memory_storage | другие пути проекта | **Никогда** без явной команды |
| Доска tldraw | браузер пользователя | Пока не на сервере |
