# Кабинет владельца Кампуса

Четыре раздела:
1. **Жалобы** — сообщения от участников (`kind=report`)
2. **Модерация** — сигналы роботов (AI / SFU) и действия ведущих (mute/kick)
3. **Баны** — активные блокировки + «Снять бан»
4. **Настройки** — образцы слов и regex для сентинелов (Campus Sentinel)

У списка: фиксированная высота с прокруткой, поиск, сортировка, фильтр.

## Localhost

1. API с `LOUNGE_OWNER_PASSWORD` из `liverooms/infra/.env`
2. `liverooms/admin` → `npm run dev` → http://127.0.0.1:5174/
3. После входа: вкладка **Настройки** — правка ключевых слов / шаблонов, «Сохранить образцы»
