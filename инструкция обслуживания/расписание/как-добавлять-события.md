# Как менять расписание Vernatun

Простая памятка для владельца сайта.  
Файл, в котором живёт календарь: `js/site.js`  
Страница на сайте: [Расписание](https://vernatunspeakclub.com/schedule)

После любых правок нужно **сохранить файл** и **выложить его на сервер** (или попросить ассистента выложить). В браузере лучше обновить страницу через **Ctrl+F5**.

---

## Два вида событий

1. **Повторяющиеся** — ставятся сами каждую неделю по правилам (четверг, суббота, воскресенье).
2. **Разовые** — одна конкретная дата (например, среда 30 сентября). Их вы дописываете руками в короткий список.

Ниже — оба способа.

---

## Часть 1. Разовое событие (одна дата)

Это самый частый случай: «добавить встречу именно в этот день».

### Куда смотреть

В файле `js/site.js` найдите (Ctrl+F):

```text
EXTRA_EVENTS
```

Сейчас там примерно так:

```javascript
var EXTRA_EVENTS = [
  { date: '2026-09-30', kind: 'talk', time: '20:00–23:00', idPrefix: 'talk-extra' },
];
```

### Как добавить ещё одну встречу

Скопируйте готовую строку и поменяйте дату, тип и время.  
Между строками нужна **запятая**.

Пример — две разовые встречи:

```javascript
var EXTRA_EVENTS = [
  { date: '2026-09-30', kind: 'talk', time: '20:00–23:00', idPrefix: 'talk-extra' },
  { date: '2026-10-05', kind: 'dance', time: '18:00–20:00', idPrefix: 'dance-extra' },
];
```

### Что писать в полях

| Поле | Простыми словами | Пример |
|------|------------------|--------|
| `date` | Дата: год-месяц-день | `'2026-10-12'` |
| `kind` | Тип встречи (см. ниже) | `'talk'` |
| `time` | Время текстом | `'20:00–23:00'` |
| `idPrefix` | Короткая метка «для компьютера» | `'talk-extra'` |

**Типы `kind` (строго одно из трёх):**

- `talk` — Разговорный клуб  
- `dance` — Танцы  
- `volleyball` — Волейбол  

Название, картинка и описание подставятся сами. Их вручную писать не нужно.

### Частые ошибки

- Дата в формате `30.09.26` — **нельзя**. Нужно `2026-09-30`.
- Забыли запятую между строками — календарь может сломаться.
- Удалили квадратные скобки `[ ]` или фигурные `{ }` — тоже нельзя.
- Тире во времени лучше **скопировать** с уже существующей строки (`20:00–23:00`), а не набирать новое «с нуля».

### Как убрать разовое событие

Удалите его строку из списка `EXTRA_EVENTS`.  
Если осталась одна строка — запятую в конце можно оставить или убрать, оба варианта нормальны.  
Если событий больше нет, список должен выглядеть так:

```javascript
var EXTRA_EVENTS = [
];
```

## Часть 2. Повторяющиеся события (каждую неделю)

Их **не нужно** каждый раз вписывать в `EXTRA_EVENTS`.  
Сайт сам рисует их на весь месяц по правилам ниже.

### Что сейчас стоит по умолчанию

| День недели | Что появляется | Время |
|-------------|----------------|-------|
| **Четверг** | Разговорный клуб | 20:00–23:00 |
| **Суббота** | По очереди: то танцы, то разговорный клуб | танцы 18:00–20:00 / клуб 15:00–18:00 |
| **Воскресенье** | Волейбол | 15:00–17:00 |

Правило суббот (с 19 сентября 2026):

- одна суббота — **танцы**,
- через неделю — **разговорный клуб**,
- и так дальше через неделю.

Понедельник, вторник, среда, пятница по умолчанию **пустые** (если вы сами не добавили разовое событие в `EXTRA_EVENTS`).

### Где менять повторяющееся расписание

Всё в том же файле `js/site.js`, функция `buildMonthEvents`.

Там есть проверки дня недели:

- `dow === 4` — **четверг** (0 = воскресенье, 1 = понедельник, …, 6 = суббота)
- `dow === 6` — **суббота**
- `dow === 0` — **воскресенье**

Внутри каждой проверки задаются:

- `kind` — тип (`talk` / `dance` / `volleyball`)
- `time` — время, например `'20:00–23:00'`

**Пример:** хотите, чтобы разговорный клуб был по **средам** 20:00–23:00 вместо четвергов.

1. Найдите блок с `dow === 4` (четверг).
2. Поменяйте `4` на `3` (среда).
3. Сохраните файл и выложите на сервер.

**Пример:** хотите другое время по четвергам.

1. В блоке четверга найдите строку `time: '20:00–23:00'`.
2. Замените на нужное, например `time: '19:00–22:00'`.

### Как сделать «каждую субботу только клуб» (без чередования с танцами)

Сейчас суббота выбирается функцией `saturdayKind` (танцы / клуб через неделю).

Простой вариант для владельца:

1. Найдите блок `if (dow === 6)`.
2. Внутри оставьте только создание события `talk` с нужным временем (как в четверге), а ветку с танцами уберите или закомментируйте.
3. Если не уверены — лучше попросите ассистента: «сделай все субботы разговорным клубом с 15:00 до 18:00».

### Как добавить новый повторяющийся день (например, каждый понедельник танцы)

Нужно добавить похожий блок:

```javascript
if (dow === 1) {
  list.push({
    id: 'dance-mon-' + key,
    date: key,
    kind: 'dance',
    kindLabel: metaDance.kindLabel,
    pillLabel: metaDance.pillLabel,
    title: metaDance.title,
    time: '18:00–20:00',
    image: metaDance.image,
    description: metaDance.description,
  });
}
```

Где `1` — понедельник.  
Номера дней:

| Число | День |
|------:|------|
| 0 | Воскресенье |
| 1 | Понедельник |
| 2 | Вторник |
| 3 | Среда |
| 4 | Четверг |
| 5 | Пятница |
| 6 | Суббота |

Если такой правки страшно — напишите ассистенту одной фразой:  
«добавь каждый понедельник танцы с 18:00 до 20:00».

## Часть 3. Тексты и картинки типов встреч

Общие тексты для «Разговорный клуб / Танцы / Волейбол» лежат выше в блоке `FORMAT_META`.

Там можно поменять:

- заголовок (`title`),
- описание (`description`),
- картинку (`image`).

Меняется сразу для **всех** встреч этого типа (и повторяющихся, и разовых).

## Часть 4. После правок — чтобы увидели гости сайта

1. Сохраните `js/site.js`.
2. На странице `schedule.html` у скрипта есть хвост версии, например:

   ```html
   <script src="/js/site.js?v=20260928a"></script>
   ```

   Можно чуть поменять хвост (`a` → `b`), чтобы у посетителей точно обновился файл, а не «залипла» старая копия в браузере.

3. Выложите на VPS обновлённые файлы:
   - `js/site.js`
   - при смене версии — ещё и `schedule.html`

   Готовый способ в проекте:

   ```powershell
   . ".\vps door\load-ssh-env.ps1"
   .\scripts\deploy_vernatun_to_vps.ps1 -SkipSsl
   ```

4. Проверьте живую страницу: https://vernatunspeakclub.com/schedule  
   Обновите через **Ctrl+F5**.

## Шпаргалка «что мне нужно сделать»

| Задача | Куда идти |
|--------|-----------|
| Одна встреча в необычный день | `EXTRA_EVENTS` |
| Другое время по четвергам / субботам / воскресеньям | блок `dow === …` в `buildMonthEvents` |
| Другой день недели постоянно | сменить номер `dow` или добавить новый блок |
| Другой текст/фото типа встречи | `FORMAT_META` |
| Чтобы увидели все в интернете | сохранить → выложить на VPS → Ctrl+F5 |

---

## Если что-то сломалось

1. Не паникуйте. Откройте предыдущую копию файла (через историю Cursor / git) или попросите ассистента откатить.
2. Проверьте запятые и кавычки в `EXTRA_EVENTS`.
3. Откройте расписание локально или на сайте и посмотрите, появляется ли день в календаре.

Этой инструкции обычно достаточно, чтобы самостоятельно вести календарь без программиста.
