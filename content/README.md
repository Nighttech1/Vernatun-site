# content/articles — источник статей (контракт для агента)

Это **единственный источник правды** для раздела «Статьи». Один файл `*.md` = одна статья.
HTML-страницы, список, навигация и sitemap **генерируются** из этих файлов и правятся только
генератором — руками их не трогаем.

> Позже источником станет внешний GitHub-репозиторий статей: клонируем его и указываем путь
> через переменную `ARTICLES_SRC`. Весь контракт ниже остаётся тем же.

## Схема файла

Имя файла = `<slug>.md`. В начале — YAML-front-matter, затем тело в Markdown:

```md
---
slug: kak-nachat-govorit        # a-z0-9 и дефисы, уникален, совпадает с именем файла
title: Как начать говорить       # <= 80 символов
category: Новичкам               # рубрика (eyebrow в списке + навигации), <= 40
description: ...                 # <= 160; meta description + og
lead: ...                        # <= 400; первый крупный абзац
date: 2026-10-31                 # YYYY-MM-DD; сортировка списка + lastmod sitemap
status: draft                    # draft | review | published
author: claude-agent
---

Абзацы тела. Пустая строка разделяет абзацы.
```

## Разрешённый Markdown (белый список)

- Абзацы (разделяются пустой строкой).
- `**жирный**`.
- `[текст](/ссылка)` — только site-relative (`/...`) или `http(s)://`.
- `## Подзаголовок`.
- Списки: строки, начинающиеся с `- `.

Любой сырой HTML и `<script>` экранируются/запрещены. Всё пишется в UTF-8 без BOM.

## Тон (домашний стиль Вернатун)

Тёплый разговор перед первой встречей, не учебник. Короткие абзацы, простые слова,
без канцелярита и «воды». Ориентир — существующие статьи `esli-stesnyaeshsya`,
`kak-prohodit-vstrecha`, `kakoi-armyanskii`.

## Жизненный цикл (гейт: черновик → апрув → публикация)

```bash
# 1. агент создаёт черновик
npm run articles:new -- --slug kak-nachat-govorit --title "Как начать говорить" --category Новичкам
#    (далее агент редактирует тело файла)

# 2. валидация
npm run articles:validate

# 3. предпросмотр локально (рендерит и черновики)
npm run articles:preview && python scripts/dev_server.py   # http://127.0.0.1:8080/articles

# 4. ЧЕЛОВЕК апрувит → перевод в published (это шаг человека, не агента)
npm run articles:publish -- --slug kak-nachat-govorit

# 5. финальная сборка (только published)
npm run articles:build
```

После шага 5 собранные файлы (`articles/*.html`, `articles.html`, `js/site.js`,
`public/sitemap.xml`) коммитятся и деплоятся на VPS существующим
`scripts/deploy_vernatun_to_vps.ps1`. **Агент сам не публикует и не деплоит** — доводит
до готового черновика и запрашивает апрув.
