# C-128 — Диалог жалобы с текстом

**P1** · W-47 · closed

## Ожидание
- Кнопка «Жалоба» открывает модалку: на кого (ник), поле текста проблемы (обязательно, ≥10 символов), отмена / отправить.
- Можно выбрать «Проблема комнаты (без участника)» — тогда target пустой/room-level; backend принимает.
- После отправки — статус «Жалоба принята»; Trust penalty только если указан target_client_id.
