### [C-146] Правая колонка ×2 шире + чат снова принимает ввод

- **Зона / Экран:** Комната → правая панель (Чат / Словарь / Разбор)
- **Факт:** `.room-col--chat` = **320px** на ≥1024px — узко. Поле чата `disabled={!connected}` — при проблеме LiveKit или гонке ввод мёртвый; пользователь «ничего не может писать».
- **Ожидание:** ширина правой колонки **~640px** (×2). Чат: можно печатать и отправлять, пока комната открыта (не блокировать ввод только из‑за «ещё подключаемся» без понятной причины; ошибка API видна).
- **Приоритет:** P0
- **Скрин-улика:** живой `/room?room=open` localhost
- **Зона:** Frontend (+ Backend если wipe/chat API мешает)
