### [C-149] Доска без входа в Spacedeck при открытии комнаты

- **Зона / Экран:** Комната → iframe доски
- **Факт:** Сейчас iframe открывает домашнюю Spacedeck → нужен логин.
- **Ожидание:** При входе в комнату доска сразу editable **без** аккаунта Spacedeck (Instant Edit Link `?spaceAuth=`). Сервисный аккаунт API создаёт Space на комнату.
- **Если невозможно:** Клиент меняет продукт доски. (Исследование: **возможно** через edit_hash.)
- **Приоритет:** P0
- **Зона:** Backend + Frontend
