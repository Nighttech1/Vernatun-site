# Guards — C-120 Dual-peer checklist + a11y mic

## Dual-peer (ручной, 2 устройства)

1. Открыть http://127.0.0.1:5173/campus (или prod `/lounge`) на ПК и телефоне / 2 браузера.
2. Войти в одну комнату (`open` или `a1`).
3. На обоих: статус «В ЭФИРЕ», в списке видны оба ахперика (не только mock).
4. Включить микрофон **по очереди** на каждом — слышно собеседника.
5. Оба говорят одновременно — оба слышат (multi-party, не Stage).
6. Выключить mic — звук с этой стороны пропадает, второй продолжает слышать если говорит.
7. Share-ссылка `/room?room=…` открывает ту же комнату.

## A11y mic (авто)

1. Кнопка `.room-btn-mic` имеет `aria-label` («Включить/Выключить микрофон»).
2. `aria-pressed` true когда mic on.

## Regression
- Mute-by-default при входе (`audio={false}`).
- Жалоба видна на remote (не только hover) — mobile tap.
