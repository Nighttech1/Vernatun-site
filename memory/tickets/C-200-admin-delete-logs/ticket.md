**P0** · W-63

- **Зона / Экран:** Owner cabinet — Жалобы / Модерация (+ по аналогии баны если уместно)
- **Факт:** Логи append-only, API удаления нет.

  - Backend: DELETE/POST purge с owner password; безопасная запись файлов (не truncate без backup-копии в рамках data-safety — копия `.bak` перед rewrite).
