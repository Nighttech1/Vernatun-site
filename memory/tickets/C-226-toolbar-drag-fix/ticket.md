### [C-226] Панель инструментов доски не перетаскивается
- **Зона / Экран:** CustomToolbar (вертикальный блок кнопок на доске)
- **Факт:** Grip/drag не двигает панель — `closest('button')` блокирует старт drag на grip-кнопке
- **Ожидание:** Панель свободно тянется за grip (и по «пустому» острову), позиция пишется в localStorage
- **Приоритет:** P1
- **Скрин-улика:** —
- **Зона:** Frontend
