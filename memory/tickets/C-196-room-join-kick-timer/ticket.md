# C-196 — Вход в комнату: «кривое» окно → выкидывает, таймер идёт

**P0** · W-63

- **Зона / Экран:** `/room` — join / LegalGate / lifecycle / LiveKit
- **Факт:** При входе появляется окно, непохожее на комнату, затем пользователя выкидывает; в лобби таймер сессии комнаты продолжает идти.
- **Ожидание:** Стабильный вход в комнату без ложного kick/superseded; таймер стартует только при реальном старте сессии комнаты и не «ломается» из‑за ложного выброса участника.
- **Приоритет:** P0
- **Зона:** Backend + Frontend + Realtime
