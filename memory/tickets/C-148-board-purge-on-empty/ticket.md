### [C-148] Удалять PDF/вложения доски при конце сеанса комнаты

- **Зона / Экран:** Backend + Spacedeck storage
- **Факт:** Файлы на доске лежат в `storage/` без авто-очистки.
- **Ожидание:** Как только в комнате **0 участников** (LiveKit подтвердил) — Space комнаты удаляется, PDF/картинки с диска тоже. Тот же триггер, что очистка чата.
- **Приоритет:** P0
- **Зона:** Backend (+ Deployer volumes)
