# C-110 — Вход в комнату сразу, без промежуточного окна

**P0** · W-42 · open

## Зона / Экран
`/room?room=` · RoomPage

## Факт
После клика «Присоединиться» открывается pre-join: доска + кнопка «Войти в комнату». Лишний шаг.

## Ожидание
При наличии `room=` сразу запрашивать token и подключаться к LiveKit (mute-by-default).  
Pre-join bar / «Нажмите Войти» — убрать.  
Пока идёт connect — короткий статус в shell (не отдельное «окно с кнопкой»).  
Ошибка token — показать сообщение + «← Все комнаты».
