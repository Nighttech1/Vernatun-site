# C-258 — Контракт публикации для агентов

- **P:** P1
- **area:** articles / agent API
- **Волна:** W-72

## Мотивация
Статьи пишет Claude-агент в отдельном чате. Ему нужен детерминированный контракт
(«API» в git-модели): схема контента + команды, чтобы создавать черновик, валидировать
и (после апрува человеком) публиковать — без знания внутренностей шаблона.

## Expected
`scripts/articles/cli.mjs` с командами `new | validate | publish | list` + `content/README.md`
с полной схемой front-matter и домашним стилем. Гейт: агент создаёт только `draft`,
`publish` (перевод в `published`) — шаг человека.

## Actual (после волны)
CLI собран, схема задокументирована, валидатор ловит обязательные поля/slug/длины/сырой HTML/кодировку.
