### [C-243] Передача прав модератора
- **Факт:** при уходе хоста права не передаются; нет ручной передачи
- **Ожидание:**
  1. Хост ушёл → права следующему по порядку входа (2-й вошедший)
  2. Хост может передать права любому участнику (меню)
  3. LiveKit metadata role=host обновляется через API
- **Зона:** Backend + Frontend
